OpenGL / OpenCV 그래픽스 과제 코드 스니펫
---

대학교 재학중 진행한 C++ / OpenGL / OpenCV를 활용한 과제 소스코드입니다.

# 프로젝트 환경
- Visual Studio 2022 환경에서 C++로 작성되었습니다
- 컴퓨터그래픽스, 애니메이션이론 (`./computergraphics`, `./animtheory`):
    - OpenGL 3.X
    - GLM
    - GLFW
    - stb_image.h
    - 교수님이 제공하신 라이브러리 & 프레임워크
- 컴퓨터비전 (`./computervision`):
    - OpenCV 5.0.0

- `./computergraphics/..`: [과목 "컴퓨터그래픽스" 최종 과제물 작성 소스코드 일부](computergraphics)
- `./animtheory/main.cpp`: [과목 "애니메이션이론" 최종 과제물 작성 소스코드 일부](animtheory/main.cpp)
- `./computervision/..`: [과목 "컴퓨터비전" 최종 과제물 작성 소스코드](animtheory)

**제가 작성하지 않은 외부 라이브러리의 경우 포함하지 않았습니다. "컴퓨터그래픽스", "애니메이션이론"의 경우, 교수님이 제공해주신 프레임워크와 스킬레톤 코드가 섞인 구간의 경우는 전체 중략시켰으니, 해당 폴더의 소스코드는 바로 실행할 수 없습니다.**
